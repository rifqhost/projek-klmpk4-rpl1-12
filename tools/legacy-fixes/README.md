# Legacy Fix Scripts

Folder ini berisi script patch sekali pakai yang pernah digunakan untuk menyisipkan fitur ke file utama aplikasi.

Script di sini tidak dipanggil oleh aplikasi saat runtime dan tidak perlu dijalankan untuk penggunaan normal. Simpan sebagai arsip teknis saja; perubahan hasil patch sudah ada di `index.php`, `views/layout.php`, `assets/js/app.js`, dan `config/database.php`.
